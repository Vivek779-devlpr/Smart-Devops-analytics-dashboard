# Smart DevOps Analytics Dashboard

A beginner-friendly React dashboard built with Tailwind CSS and Chart.js. It displays sample DevOps metrics with charts, cards, and insight logic.

## Features

- Dark theme with modern UI
- Responsive layout for laptop and mobile
- Metrics cards for success rate, deployment frequency, build time, and failure rate
- Line chart for build time trend
- Bar chart for deployments
- Pie chart for success vs failure
- Alert section and simple insights logic
- Refresh button to simulate new data
- Filter last 7 or 10 days

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start development server:

```bash
npm run dev
```

3. Open the local URL shown in the terminal.

## Project structure

- `src/App.jsx` — main dashboard layout and logic
- `src/components/` — reusable UI and chart components
- `src/data/dashboardData.js` — sample JSON dataset
- `src/index.css` — Tailwind styles and page background

Enjoy exploring the dashboard! 🎯
